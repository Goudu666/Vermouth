# UI_PROPOSALS：界面与体验改进方案

> 现有界面（Antigravity 完成的 v0.1）是规整的 macOS 原生工具风格：功能齐全、信息透明，但**视觉上偏「设置面板」而不像「游戏启动器」**，
> 截图放在 README 或作品集里不够抓眼。下面的方案保留原生质感（SF Symbols、系统材质、深浅色自适应），只在关键位置加「记忆点」。
> 状态：⏳ 待做 · 🚧 进行中 · ✅ 已落地。

## 设计方向：「酒柜」隐喻

Vermouth（味美思）是一种加香葡萄酒。把每个容器想成酒柜里的一瓶酒：有自己的颜色（图形后端）、标签（Windows 版本）和年份（引擎版本）。
主色取**味美思琥珀**（暖琥珀 → 勃艮第酒红的渐变），只用在品牌位置（图标、空状态、主按钮），其余保持系统中性色，避免花哨。

## 第 1.5 批：普通模式（2026-11-20，用户反馈「技术细节露得太多」）

| # | 改动 | 说明 | 状态 |
|---|---|---|---|
| A | **程序库成为默认界面**（`LibraryView`） | 所有容器里固定的程序汇成一面封面墙；双击或悬停播放键启动，卡片显示运行中 / 停止；不出现「容器 / 引擎 / DXMT」等词 | 🚧 CI 编译通过，待真机看观感 |
| B | **拖入即添加** | 按文件名猜「安装包」还是「免安装程序」（`ProgramFileClassifier`），确认一次即可；安装包装进自动创建的默认环境「我的 Windows」，装完自动收录新程序（`InstalledProgramAdopter`） | 🚧 |
| C | **一键准备运行环境**（`EnvironmentSetupPanel`） | 预检翻译成白话步骤（`EnvironmentSetupPlanner`），Rosetta / Homebrew / Wine / winetricks 合成一条终端脚本；隔离属性在 App 内直接解除；回到 App 自动重新检测 | 🚧 |
| D | **问题助手**（`ProblemAssistantSection`） | 运行结束后用 `LaunchOutcomeEvaluator` 判断，只在崩溃或有诊断时提示，附一键修复 | 🚧 |
| E | **高级模式** | 原工作台原样保留，⇧⌘A 或「更多 › 切换到高级模式」进入，工具栏「返回程序库」回来 | ✅ |

设计原则：默认路径上不出现任何需要懂 Wine 才能理解的词；技术信息不删，统一折叠在「程序详情 › 技术详情」与高级模式。

## 约束

- 所有新视图放在 `Sources/VermouthApp/`，不引入第三方 UI 库；色值集中在 `VermouthTheme`，不在视图里写死。
- 新的解析能力（如 PE 图标）一律放 `VermouthCore` 并配单测，App 层只做展示（ARCHITECTURE 不变量：Core 与 UI 解耦）。
- 云端 Agent 无法编译 SwiftUI：每批 UI 改动必须拿到 macOS CI 绿灯；观感需用户或 Antigravity 在真机确认后才算 ✅。
